# Candidate Evaluation Results

이 문서는 **244개 신규 대기거점 후보를 동일한 조건에서 평가한 결과**를 정리합니다. 모델 구조는 [Methodology](methodology.md), 데이터 검증은 [Data Validation](data_validation.md)을 참고하세요.

## 1. Evaluation Setup

| 항목 | 설정 |
|---|---|
| 후보 | **244곳** |
| 반복 | Seed **42 · 43 · 44** |
| 총 평가 결과 | **732행** |
| 재생 기간 | 2025-08-20 ~ 2025-09-18, 30일 |
| 개입 | 신규 거점 배속 정원 +10대, 기존 44개 거점 배속 유지 |
| 평가 범위 | 후보지 중심 **3km 영향권** |
| 주요 지표 | 픽업시간 개선율 |
| 함께 보는 지표 | 절대 Δ, 총 절감량, 콜 수, 동 수, 반복실험 변동, 구간 중첩 수 |

3km는 시뮬레이션 계산 단위가 아니라 **결과 집계 범위**입니다. 모델 자체는 행정동 단위로 움직이며, 후보에서 3km 안에 들어오는 동의 결과를 묶어 평가합니다.

파일럿 후보에서 3km 영향권의 평균 픽업 감소폭은 −0.441분으로 서울 전체 평균 −0.058분보다 약 **7.6배** 크게 나타나, 위치 효과가 서울 전체 평균에 희석되는 문제를 줄일 수 있었습니다.

## 2. Main Results

244개 후보가 모두 3개 seed를 완료했고, 후보·seed 중복이나 결측 결과는 없었습니다.

| 지표 | 결과 |
|---|---:|
| 후보 수 | 244 |
| 반복 결과 | 732 |
| 개선율 범위 | **−8.57% ~ −1.48%** |
| 개선율 중앙 | **−2.91%** |
| seed 간 표준편차 중앙 | **0.597%p** |
| 평가 구간 반폭 중앙 | **±0.844%p** |

모든 후보에서 시뮬레이션상 픽업시간 개선이 관측됐지만, 절대 효과 크기는 모델 한계를 포함하므로 후보 간 비교값으로 해석합니다.

## 3. Uncertainty

후보 효과는 단일 실행값이 아니라 3개 seed의 반복 결과로 평가했습니다. `rate_sd`로 seed 간 변동을, 각 후보의 평가 구간으로 반복실험 불확실성을 표현했습니다.

후보 간 효과 차이가 반복실험 변동보다 작은 경우가 많았습니다. **개선율이 가장 큰 후보의 평가 구간은 다른 24개 후보와 겹쳤습니다.** 후보에 따라 중첩 정도가 크게 달라, 각 후보마다 다음 값을 함께 산출했습니다.

- `rate_sd`: seed 간 개선율 표준편차
- `interval`: 반복실험 기반 평가 구간
- `n_overlap`: 해당 구간과 겹치는 다른 후보 수
- `sample_ok`: 3km 영향권의 콜 수가 충분한지 표시

`n_overlap`은 값이 클수록 현재 반복실험 범위에서 다른 후보들과 효과를 분리해 읽기 어렵다는 뜻입니다.

### Sample size effect

3km 콜이 2,000건 미만인 후보는 12곳으로 전체의 4.9%였습니다. 이 후보들은 개선율의 변동 구간이 상대적으로 넓었습니다.

| 구분 | 2,000건 미만 12곳 | 나머지 232곳 |
|---|---:|---:|
| 평균 개선율 | −5.86% | −3.14% |
| 평가 구간 폭 중앙 | **2.87%p** | **1.68%p** |
| 3km 콜 중앙 | 1,721 | 4,846 |

따라서 개선율은 반드시 영향권 콜 수와 함께 읽습니다.

## 4. Metric Interpretation

### Improvement rate

`개선율 = (after − before) / before × 100`

해당 후보 주변 이용자의 평균 픽업시간이 **기존 수준 대비 얼마나 줄어드는지**를 나타냅니다. 지역마다 before가 다르기 때문에 절대 감소분만 비교할 때 생기는 출발점 차이를 보정합니다.

### Total saving

`총 절감량 = 픽업 감소분 × 영향권 콜 수`

효과가 **얼마나 많은 이용자에게 누적되는지**를 나타냅니다. 개선율이 커도 콜 수가 적으면 총 절감량은 작을 수 있습니다.

두 지표의 Spearman ρ는 **0.32**였고, 각 지표의 상위 20개 후보 중 공통 후보는 **4곳**이었습니다. 즉 개선율과 총 절감량은 같은 효과를 다른 단위로 표현한 것이 아니라, 각각 **개선 정도**와 **수혜 규모**라는 다른 측면을 측정합니다.

## 5. Model Selection Decisions

결과를 더 잘 맞추는 설정을 발견했더라도, 독립적인 검증 지표를 훼손하면 채택하지 않았습니다.

### Idle-break threshold θ — not adopted

유휴시간이 일정 길이를 넘으면 차량을 일시적으로 비가용 처리하는 θ를 탐색했습니다. θ를 줄이면 매칭·총 대기 수준은 실측에 가까워졌지만, 독립 검증 지표는 반대 방향으로 움직였습니다.

- 실측 평일 동시 유휴 최대: **164.6대**
- θ 없음: **163.5대**
- θ=20분: **148.6대**

대기 수준을 맞추기 위해 θ를 강하게 적용할수록 이미 실측과 가까운 공급 구조가 멀어졌습니다. 따라서 θ는 기본 모델에 적용하지 않았습니다.

### Candidate filter — not adopted

실제 시스템이 가장 가까운 차량을 항상 선택하지 못하는 현상을 표현하기 위해 배차 후보를 무작위로 줄이는 설정을 시험했습니다.

`keep_p=0.05`에서는 픽업 중앙값이 실측 17.76분과 거의 일치했고 평균·p90도 가까워졌지만, 픽업 지니는 다음과 같이 악화됐습니다.

| 설정 | 픽업 지니 |
|---|---:|
| 실측 | **0.0751** |
| 필터 없음 | **0.0805** |
| random keep 5% | **0.0519** |

절대 픽업시간을 맞추는 대신 거점 배치가 개선하려는 **지역 간 공간 격차 구조가 사라졌기 때문에** 해당 설정을 채택하지 않았습니다.

## 6. Sensitivity Analysis

본실행 결과 중 표본이 충분한 대표 후보 9곳을 이용해 주요 가정을 변경했습니다. 각 설정은 동일한 콜 단위 난수를 사용해 설정 변화 자체의 영향을 비교했습니다.

| 설정 | Spearman ρ (n=9) | 9곳 평균 개선율 |
|---|---:|---:|
| 기본 | 1.000 | −3.71% |
| 근접 가중 강화 | 0.950 | −3.63% |
| 대기 가중 강화 | 0.917 | −4.00% |
| 심야 반경 7km | 0.683 | −3.97% |
| θ=120분 | 0.883 | −3.80% |
| θ=60분 | 0.867 | −3.05% |

큰 효과와 작은 효과의 구분은 대부분의 설정에서 유지됐지만, 일부 후보의 세부적인 상대 위치와 효과 크기는 가정에 민감했습니다. 특히 θ는 신규 차량도 함께 비가용 상태가 될 수 있어 효과 크기를 줄이는 방향으로 작동했습니다.

## 7. Limitations

- 현행 배치 재생에서 픽업시간의 절대 수준이 실측보다 짧습니다.
- 실제 기사 수락·거절·차량 상태·사전 점유가 배차 후보군을 어떻게 줄이는지 직접 관측하지 못했습니다.
- 유휴차량을 별도 휴게 상태로 구분하지 않아 절대 효과 크기에 반대 방향의 편의가 존재할 수 있습니다.
- 3개 seed만 사용하므로 후보별 표준편차 추정 자체에도 불확실성이 있습니다.
- 후보 풀은 옥외 주차장으로 제한되어 일부 도심 지역의 실행 가능한 대안을 충분히 포함하지 못할 수 있습니다.
- 민감도 분석은 대표 9곳과 일부 가정만을 대상으로 했습니다.

따라서 결과는 **후보 간 상대적 효과, 영향 범위, 수혜 규모, 불확실성을 함께 비교하는 자료**로 사용합니다.
