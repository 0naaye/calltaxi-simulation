# 서울 장애인콜택시 대기거점 배치 시뮬레이션
2025년 서울 장애인콜택시 특장차 운행 데이터를 분석하고, **이산사건 시뮬레이션(Discrete Event Simulation)** 으로 신규 대기거점 후보 244곳의 효과를 비교한 의사결정 지원 프로젝트입니다.

> 팀 프로젝트 결과를 개인 포트폴리오용으로 재구성한 저장소입니다. 프로젝트 전체 성과와 개인 기여는 구분해 작성합니다.

## Overview

| 항목 | 내용 |
|---|---|
| 문제 | 행정동별 장애인콜택시 대기 격차와 거점 접근성 차이 |
| 목표 | 신규 대기거점 후보별 효과를 동일한 조건에서 비교 |
| 분석 데이터 | 2025년 특장차 운행 원본 1,390,969건 → 분석 입력 1,222,330건 |

| 결과물 | Streamlit 기반 진단·후보 비교 대시보드 |

## Approach

```mermaid
flowchart LR
    A[운행 데이터] --> B[전처리·행정동 정합화]
    B --> C[동별 대기·수요·공급 진단]
    C --> D[대기거점 후보 구성]
    D --> E[Call–Vehicle DES]
    E --> F[244개 후보 × 3 Seeds]
    F --> G[개선율·총절감·불확실성 평가]
    G --> H[Streamlit Dashboard]
```

시뮬레이션은 **콜**과 **차량**을 별도 개체로 두고, 차량이 `대기 → 배차 → 공차 이동 → 승차 → 운행 → 하차 → 대기`를 반복하도록 구성했습니다. 실제 데이터에서 차량 공급, 교대 패턴, 이동시간, 취소·인내심을 추정해 입력으로 사용했습니다.

## Key Results

- **분석 모집단 정제** — 특장차 원본 1,390,969건에서 즉시콜·서울 출발 조건을 적용해 1,222,330건을 구성하고, 행정동 표기 차이를 exact / approx / manual 3단계로 정합화했습니다.
- **후보 전수 평가** — 244개 후보를 Seed 42·43·44로 반복해 총 **732개 시뮬레이션 결과**를 생성했습니다. 후보별 개선율 중앙값은 −2.91%, 범위는 −8.57% ~ −1.48%였습니다.
- **비교 잡음 축소** — 콜 ID와 차량 Slot 기반 공통난수를 적용해 동별 픽업시간의 난수 변동을 약 **0.465분 → 0.039분**으로 줄였습니다.
- **효과와 수혜 규모를 분리** — 개선율과 총 절감량의 Spearman ρ는 **0.32**였고, 각 지표의 상위 20개 후보 중 공통 후보는 4곳이었습니다. 두 지표가 서로 다른 정책 효과를 측정한다는 점을 확인했습니다.
- **불확실성 병기** — 후보별 반복실험 변동과 평가 구간을 계산했으며, 개선율이 가장 큰 후보의 구간은 다른 **24개 후보**와 겹쳤습니다. 후보별 `n_overlap`으로 구간 중첩 정도를 함께 산출했습니다.

## Model Scope & Limitation

현행 배치 재생에서 **픽업시간의 절대 수준은 충분히 재현되지 않았습니다.** 대표 기간 기준 픽업 중앙값은 실측 17.76분, 시뮬레이션 9.45분이었습니다. 반면 공간 격차를 나타내는 픽업 지니는 실측 0.0751, 시뮬레이션 0.0805로 비교적 가까웠습니다.

따라서 결과는 **절대적인 “몇 분 감소” 예측보다 동일한 조건에서 후보 간 상대적 효과를 비교하는 용도**로 사용합니다. 절대 효과 크기는 모델의 매칭·배차 단순화와 유휴차량 가정에 서로 다른 방향의 편의가 있어 별도로 해석해야 합니다.

## Run

대시보드는 공개 가능한 파생 산출물만으로 실행할 수 있도록 구성했습니다.

```bash
pip install -r requirements.txt
streamlit run src/dashboard.py
```

전체 분석·시뮬레이션 재실행에는 원본 운행 데이터가 필요합니다. 원본은 개인정보 및 이용 조건 때문에 저장소에 포함하지 않습니다.

- 원본 콜 운행 데이터는 공개하지 않습니다.
